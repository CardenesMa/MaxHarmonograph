There is an issue when loading up the Ableton live session when using "collect all and save". It conveniently forgets the javascript files and leaves them behind. The only way for the project to work is for these files to exist, or have their contents copied into the relevant JS patch objects.

If it isn't working as expected, open the source of the patch contents, and copy paste in these files. You will need to recconect the now missing patch chords back together as well.
